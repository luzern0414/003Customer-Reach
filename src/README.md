# 源码目录

建议按数据生命周期拆分模块：

- `collectors/`：HTTP/API/浏览器采集器，只负责获取原始响应和元数据
- `adapters/`：按来源实现的适配器；企查查、1688 等在完成授权审查前只保留接口约定
- `normalizers/`：企业名称、地址、经营范围、产品和电话标准化
- `entity_resolution/`：统一社会信用代码优先的企业/联系人去重
- `evidence/`：来源快照、证据片段、时间和置信度
- `lead_scoring/`：可解释的线索评分和评分版本
- `product_matching/`：经营范围/采购信号到产品候选的匹配
- `pipeline/`：任务编排、重试、人工复核和导出
- `agent/`：后续接入 CRM Agent 的工具边界和审批动作

采集器不得直接写入已确认客户主数据，应先写入原始记录和事实候选，经过规则或人工核验后再进入 CRM。
