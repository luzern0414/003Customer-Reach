# 初代CRM数据库

2026-10-01，Codex。SQLite `data/app/clientreach.db`；以下来自当前SQLAlchemy模型编译，先建表再建索引。
初次创建新库，无ALTER、DROP、删除历史资料。应用通过create_all只补缺失表；此DDL不要在已有同名表的库重复直接执行。
UUID、时间、状态、数组默认值由ORM提供，不是数据库DEFAULT。初代关系ID没有数据库外键约束，由Service校验。WAL及foreign_keys PRAGMA开启不意味着现有表已定义外键。

```sql
CREATE TABLE attachments (id VARCHAR NOT NULL PRIMARY KEY, filename VARCHAR, stored_path VARCHAR, size INTEGER, text TEXT, truncated BOOLEAN, created_at VARCHAR);
CREATE TABLE conversations (id VARCHAR NOT NULL PRIMARY KEY, title VARCHAR, profile JSON, created_at VARCHAR, updated_at VARCHAR);
CREATE TABLE evidence (id VARCHAR NOT NULL PRIMARY KEY, job_id VARCHAR, url TEXT, title TEXT, body TEXT, kind VARCHAR, captured_at VARCHAR);
CREATE TABLE followups (id INTEGER NOT NULL PRIMARY KEY, lead_id VARCHAR, content TEXT, kind VARCHAR, created_at VARCHAR);
CREATE TABLE job_events (id INTEGER NOT NULL PRIMARY KEY, job_id VARCHAR, stage VARCHAR, message TEXT, level VARCHAR, created_at VARCHAR);
CREATE TABLE jobs (id VARCHAR NOT NULL PRIMARY KEY, conversation_id VARCHAR, client_token VARCHAR UNIQUE, prompt TEXT, attachment_ids JSON, status VARCHAR, stage VARCHAR, progress INTEGER, cancel_requested BOOLEAN, lead_ids JSON, error TEXT, created_at VARCHAR, updated_at VARCHAR);
CREATE TABLE leads (id VARCHAR NOT NULL PRIMARY KEY, dedupe_key VARCHAR UNIQUE, display_name VARCHAR, legal_name VARCHAR, city VARCHAR, industry VARCHAR, status VARCHAR, owner VARCHAR, next_followup VARCHAR, score INTEGER, match_reason TEXT, matched_products JSON, facts JSON, evidence JSON, manual_fields JSON, tags JSON, archived BOOLEAN, created_at VARCHAR, updated_at VARCHAR);
CREATE TABLE messages (id INTEGER NOT NULL PRIMARY KEY, conversation_id VARCHAR, role VARCHAR, content TEXT, attachment_ids JSON, created_at VARCHAR);
CREATE TABLE settings ("key" VARCHAR NOT NULL PRIMARY KEY, value JSON);
CREATE INDEX ix_evidence_job_id ON evidence (job_id);
CREATE INDEX ix_followups_lead_id ON followups (lead_id);
CREATE INDEX ix_job_events_job_id ON job_events (job_id);
CREATE INDEX ix_jobs_status ON jobs (status);
CREATE INDEX ix_jobs_conversation_id ON jobs (conversation_id);
CREATE INDEX ix_leads_display_name ON leads (display_name);
CREATE INDEX ix_leads_status ON leads (status);
CREATE INDEX ix_messages_conversation_id ON messages (conversation_id);
```
