# 工具恢复账本补列

2026-10-03，Codex。SQLite非破坏性补列，由app.db.initialize按缺列逐条执行；已存在列跳过，不删除客户、证据或工具历史。

```sql
ALTER TABLE tool_calls ADD COLUMN attempts INTEGER DEFAULT 1;
ALTER TABLE tool_calls ADD COLUMN last_attempt_epoch FLOAT DEFAULT 0;
ALTER TABLE tool_calls ADD COLUMN retry_after_epoch FLOAT DEFAULT 0;
```

attempts累计执行尝试（恢复不退额度）；last_attempt_epoch区分同轮失败与显式恢复；retry_after_epoch是冷却截止Unix秒。历史缺失时间保持0，不编造旧请求时间。elapsed_ms累计各次尝试，前端同时展示次数。

错误类别和host存于既有result JSON。供应商冷却跨任务，站点只限制同host；Retry-After接受秒数/HTTP日期，无效默认60秒，不缩短服务器要求。
