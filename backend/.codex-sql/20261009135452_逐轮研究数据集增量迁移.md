按如下顺序执行，冻结DDL对应 `backend/migrations/versions/20261009_03_research_datasets.py`：

```sql
CREATE TABLE research_datasets (
  id VARCHAR NOT NULL PRIMARY KEY,
  unique_key VARCHAR NOT NULL UNIQUE,
  job_id VARCHAR NOT NULL REFERENCES jobs(id),
  conversation_id VARCHAR NOT NULL REFERENCES conversations(id),
  company_id VARCHAR REFERENCES companies(id),
  phase VARCHAR NOT NULL,
  status VARCHAR,
  source_ids JSON,
  payload JSON,
  cleaning_version VARCHAR,
  model_version VARCHAR,
  created_at VARCHAR,
  updated_at VARCHAR
);
CREATE INDEX ix_research_datasets_job_id ON research_datasets(job_id);
CREATE INDEX ix_research_datasets_conversation_id ON research_datasets(conversation_id);
```

phase：clean / extract / save / review / final。clean保留全文或搜索摘要的清洗结果与原文连续区间；extract为未核验结构化提议；save保留逐项接受/拒绝与记录引用；review为缺口与下一轮决策；final为真实终态。只有已通过原文与主体核验的记录进入CompanyFact/采购/关系表。

SQL不含数据库server default，业务默认由SQLAlchemy赋值。cleaning_version标记清洗策略，model_version标记提取模型；时间统一Asia/Shanghai的 `yyyy-MM-dd HH:mm:ss`。

降级不自动DROP表。需要回退时，应停机并一致恢复迁移前业务库与checkpoint，同时回退后端代码；这会丢弃备份之后的新资料，不能只回退其中一个数据库。
