# v0.2数据库增量

2026-10-02，Codex。SQLite本地业务库；执行入口backend/app/db.py initialize()。修改前备份于.codex-tmp/v2-backup/clientreach-before-v2.db；以下按既有v0.1结构列出SQL，不重复执行已经存在的列。实际迁移检查PRAGMA列名后才执行ALTER。

## 新建表

```sql
CREATE TABLE IF NOT EXISTS memories (
 id VARCHAR PRIMARY KEY, namespace VARCHAR, key VARCHAR,
 unique_key VARCHAR UNIQUE, value JSON, status VARCHAR,
 created_at VARCHAR, updated_at VARCHAR
);
CREATE INDEX IF NOT EXISTS ix_memories_namespace ON memories(namespace);
CREATE TABLE IF NOT EXISTS knowledge (
 id VARCHAR PRIMARY KEY, unique_key VARCHAR UNIQUE, workspace_id VARCHAR,
 title VARCHAR, body TEXT, kind VARCHAR, source_id VARCHAR, source_url TEXT,
 entity_id VARCHAR, status VARCHAR, expires_at VARCHAR,
 created_at VARCHAR, updated_at VARCHAR
);
CREATE INDEX IF NOT EXISTS ix_knowledge_workspace_id ON knowledge(workspace_id);
CREATE TABLE IF NOT EXISTS feedback (
 id VARCHAR PRIMARY KEY, lead_id VARCHAR, kind VARCHAR, content TEXT, created_at VARCHAR
);
CREATE INDEX IF NOT EXISTS ix_feedback_lead_id ON feedback(lead_id);
CREATE TABLE IF NOT EXISTS tool_calls (
 id VARCHAR PRIMARY KEY, job_id VARCHAR, operation_id VARCHAR UNIQUE,
 tool VARCHAR, channel VARCHAR, arguments JSON, result JSON,
 status VARCHAR, elapsed_ms INTEGER, created_at VARCHAR, updated_at VARCHAR
);
CREATE INDEX IF NOT EXISTS ix_tool_calls_job_id ON tool_calls(job_id);
CREATE VIRTUAL TABLE IF NOT EXISTS knowledge_fts
 USING fts5(item_id UNINDEXED,workspace_id UNINDEXED,title,body);
```
