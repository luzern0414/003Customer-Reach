# 安装 CLI 工具
npm install -g qcc-agent-cli

# 绑定 API Key（一次性操作）
qcc init --authorization "Bearer YOUR_API_KEY"

# 查询企业工商登记信息
qcc company get_company_registration_info "企查查科技股份有限公司"

# 法律法规 · 法规检索
qcc regulation get_legal_regulation_search "数据出境"
# 司法案例 · 类案检索
qcc case get_judicial_case_search "卖方违约的买卖合同纠纷判决"

# 标讯数据 · 招投标搜索
qcc tender search_tenders "智慧工地"

# 智能文档解析 · 本机文件或在线链接
qcc document parse_document --file_path "./财报.pdf"
qcc document parse_document --file_url "https://example.com/财报.pdf"
# 长文档异步 · 按任务编号查询结果
qcc document get_parse_result "TASK_ID"
CLI 典型用途：在接入 MCP 之前，用 CLI 验证数据质量（不经过 LLM 推理）；在 Agent 自动化流程中，用 CLI 做确定性的数据获取步骤；在 CI/CD 管道中集成企业数据核验。CLI 和 MCP 互补，共用同一套 API Key 与权益额度。

常见问题

接入过程中遇到问题？这里列出常见的情况。还找不到解决方案，可致电 400-088-8275。

一、积分与额度

企查查 MCP 怎么收费？现在需要付费吗？+

企查查智能体平台已推出“开发者支持计划”：注册成功即赠送体验积分，每日还会自动赠送积分。如赠送积分不够用，现已支持在线充值购买（1 元 = 10 积分），自助操作、即时到账。

一页看懂积分体系（领取 / 消耗顺序 / 充值规则）：积分说明

每天／注册能领多少积分？不同会员有区别吗？+

新用户注册成功即领 500 体验积分（有效期 30 天）。此外系统每日赠送积分、当日有效，按会员等级区分：普通用户 100/天，企查查 VIP 150/天，SVIP 200/天。

调用一次查询消耗多少积分？+

不同工具消耗的积分不同，每一个工具的积分单价可在该工具的详情页中查看。

担心智能体反复调用、乱消耗积分？有没有上限？+

不用太担心。为防止智能体无效循环调用、乱消耗积分，我们在计费上设置了费用封顶机制：同一个被查询主体在一个自然月内有积分消耗上限

个体工商户：20 积分 / 自然月

企业：100 积分 / 自然月

董监高人员：100 积分 / 自然月

积分／额度不够用怎么办？如何获取更多积分？+

可通过以下方式获取积分（注册 / 赠送 / 认证 / 邀请均为活动赠送，规则可能调整，以官网为准）：

1、在线充值（推荐）：1 元 = 10 积分，即充即用，套餐 50/100/500 元或自定义，支持微信、支付宝、对公转账；

2、注册体验积分：新用户注册成功即领 500 积分（有效期 30 天）；

3、每日赠送积分：系统每日自动发放、当日有效，普通 100/天 / 企查查 VIP 150/天 / SVIP 200/天；

4、认证奖励积分：完成企业实名认证赠送 200 积分（90 天有效）；

5、邀请奖励积分：好友注册并激活调用 MCP，每激活 1 人得 100 积分，每月最多 5 人（90 天有效）；

6、企业大批量使用：可联系商务 400-088-8275 对接处理。

在线充值的规则和渠道是什么？+

在线充值已正式上线，即充即用、自助操作、无需联系商务：

1、兑换比例：1 元 = 10 积分；

2、充值套餐：50 元 / 100 元 / 500 元，也支持自定义金额；

3、支付方式：微信支付、支付宝、对公转账。

每日依旧赠送积分，充值可用于在赠送积分不足时进行补充。

调用时提示积分不足要怎么处理？+

积分不足可按以下方式处理：

1、先确认是否还有可用的赠送积分（每日赠送的积分可能尚未生效或已用完）；

2、如已没有可用积分，可直接在线充值购买（1 元 = 10 积分，即时到账）；

3、也可通过升级会员、完成企业认证、邀请好友等方式获取更多积分。

企业大批量调用 / 大额采购如何申请？+

大额采购或企业订购可联系商务：400-088-8275。

二、API Key 与接入配置

在哪里获取我的 API Key？+

登录后，点击右上角头像，在下拉菜单中选择“获取我的 API KEY”（即个人中心）即可获取。

API Key 可以更改或重置吗？+

API Key 的名称 / 备注可以编辑，但密钥本身目前不支持直接重置或在原 Key 上换新。如需更换（例如不慎泄露），请在「获取 API Key」页新建一个 Key，将新的 Key 或专属 MCP 配置 JSON 更新到对应应用并确认可用后，再删除旧 Key。删除后旧 Key 会立即失效且不可恢复；每个账号至少保留 1 个 Key，最多可创建 5 个。

支持哪些终端／AI 应用？+

支持的应用分两类，按需选择即可：

① 已打通，登录即可直接用（无需任何配置）

在这些应用里，用企查查账号登录、点一下“同意/授权”就能直接使用，不用手动填配置：

WorkBuddy、QoderWork、IMA（ima.copilot）

② 其他支持 MCP 的应用（粘贴配置后使用）

把企查查的接入配置复制粘贴进去就能用，常见的有：

Claude Desktop、CherryStudio、Trae、Cursor、阿里云百炼、Codex 等

CLI 和 MCP 能同时用吗？+

可以。两者共用同一个 API Key、查询同一个数据源，互不冲突：MCP 适合在 AI 对话中用自然语言调用，CLI 适合脚本自动化和 CI/CD 批量处理。首次使用 CLI 时，用 qcc init 绑定 API Key 即可。

如何把服务接入到我自己的系统或应用中？+

登录后在个人中心获取 API Key 与接入 URL，将接入 URL 直接提供给大模型即可使用。详细接入方式可参考接入指南：https://agent.qcc.com/guide

在 WorkBuddy 中开启连接器后只有一个 server，如何连上全部 server？+

WorkBuddy 连接器里的“企查查”默认仅对应 1 个 Server（qcc-company）。如需使用全部 10 个 Server，请到我们平台获取 API Key，用该 API Key 自定义配置即可一次性连上；智能文档解析会同时提供本地文件上传与在线链接解析配置。

查询结果能否翻页？为什么有些 MCP 工具只返回部分数据？+

部分 MCP 工具（如商标、专利等）支持翻页。如确需翻页，可向我们申请并说明原因，开通后即可使用。

翻页会额外消耗积分，建议让 AI 按需调用、避免无意义的反复翻页造成浪费。

三、实名认证

必须企业实名认证吗？认证后有什么权益？+

认证不是必须的：平台共 10 个 server，只有“历史存档 server”需要完成企业认证后才能使用，其余 9 个无需认证即可直接使用，个人用户也能正常使用。

完成企业实名认证后可获得以下权益：

1、自动开通“历史存档 server”，无需额外申请；

2、API Key 保持不变，原有配置可继续使用；

3、额外获得认证奖励积分 200（90 天有效）。

实名认证的对公汇款，认证完成后会退还吗？+

会的。认证处理完成后，系统会自动将对公汇款原路退回，无需额外操作。

如何开通并使用历史存档 server？+

历史存档 server需先完成企业认证。认证通过后，系统会自动为您开通历史存档 server，无需额外申请，即可直接调用历史存档相关工具。

个人用户／教师／机关单位如何完成认证？+

可联系我们的商务同事，协助您完成认证与积分赠送事宜（可能需提供相应证明材料，如教职证明等）。

四、调用异常与技术排障

WorkBuddy 提示“暂未完成授权／可能存在重复连接配置”或授权失败？+

这种情况通常是连接配置冲突导致的：连接器市场里的“企查查”对应的就是 qcc-company，它可能与自定义配置里的 qcc-company 互斥，无法同时连接。

建议的解决方案：如果你已在自定义配置里添加了企查查 MCP，可以先把连接器市场里的“企查查”关闭，以避免冲突，通常自定义配置中的全部服务即可正常使用。

历史存档 server无法连接／调用怎么办？+

历史存档 server需认证通过后才能使用。请先完成认证，认证通过后再重试调用。

提示 invalid_token、身份凭证校验失败、请重新配置 Bearer Token？+

该 Token 无效或已过期。请重新在个人中心“获取我的 API KEY”，并用最新 Key 重新配置 Authorization Bearer Token。
