## 实现与口径

- 官方MCP SDK优先绝对入口，核对真实tools/list，固定四工具白名单，调用路径不由模型选择。
- history企业研究默认最多5页、100条导航；recent按本轮明确窗口筛选，统一入口约束补查。列表仅授予详情URL许可。
- get_tender_detail只读本任务已发现并许可的来源URL。独立调用上限；共用任务读取/请求预算，每次预留1读和最多8个含跳转请求；失败与显式恢复累计。
- 每页完成即保存，候选/备选/第二中标人按连续原文。705768958/705768844正文中的“备选供应商中标人”按备选记，不授予已成交客户。
- 同日期/同标题及实质正文完全一致，仅排版或末尾来源说明不同的转载合并，两份Evidence保留。旧键重读兼容、跨任务来源追加；角色纠正后重算公开公告支持的关系，旧无支持关系保留并从投影排除。
- 网络列表失败只作一次有界恢复，企业history允许1小时有效缓存，保留最初失败报告及reused状态；访问拒绝/验证码/robots不换读取器；站点限流按同host挡板，至少60秒且明确恢复才再试。
- 已核原生公告不重复进模型事实提取。回答使用实际已保存事实、具体公告及角色，不补遮挡值，不生成授权来源伪链接。
- 企业页展示线索、正文、角色、过滤/失败原因及具体记录；工具轨迹保留详情调用。
- 初次与恢复共用 `collect_company_mcp`。恢复检索继续补读未尝试公告；恢复详情按同Job账本重新统计并消费先前成功记录。成功正文不重发，详情尝试累计，失败数表示最新结果仍失败的操作，原失败事件保留。
