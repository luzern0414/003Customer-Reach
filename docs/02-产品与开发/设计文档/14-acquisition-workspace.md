# 企业获客工作台

2026-10-13。面向企业销售，把具体采购需求、产品适配核验与客户跟进放进同一流程。企业与采购 MCP 已接入原 Agent，接入配置与检索验收见 [13-agent-mcp.md](13-agent-mcp.md)。

## 企业用户如何使用

1. 在工作台介绍产品、交付能力和目标市场，或上传产品资料。写明支持的部署方式、接口、行业案例和能力边界；没有披露的能力保持未知。
2. 提交具体获客需求，例如：“检索近30天正在采购软件开发或AI服务的买方，最多3家，给出项目号、采购人、需求原文、预算口径、响应截止和原始公告；排除供应商宣传，合并转载。”需要交叉验证时明确“每客户至少2个网站”，系统保留未满足的覆盖缺口。
3. 在工作台右侧直接查看机会卡，或打开“查询结果 → 获客线索”。支持客户名称、跟进状态和产品对话筛选；“企业档案”视图保留工商、采购和上下游综合研究。
4. 打开客户详情，先看实际采购人、项目号、公告状态、截止时间和需求原文，再看产品匹配依据与待核条件。组合公告无法定位独立项目时不借用其他买方的金额或规格。
5. “AI 匹配分析 / 重新分析”使用当前产品对话与该客户的归档资料，可补充评估重点。按钮排入原 Worker，工作台展示真实任务过程，继续沿用预算、暂停和恢复。
6. 分配负责人、安排下次跟进、记录实际沟通。纠错或失效反馈会影响后续分析；跟进日期只是本地CRM安排，不代表已经设置外部提醒或发送消息。

客户编辑及导出入口保留在“管理客户与导出”。公开联系方式不等于采购负责人，也不表示号码已接通；应先确认岗位及用途，再开展销售沟通。

## 展示与分析口径

客户详情 `/opportunities/:id` 显示逐公告的买方、项目编号、预算/限价/成交口径、期限、需求、全部已保存事实、字段证据、来源和CRM活动。长原文折叠，归档全文在显式点击后读取。需求章节超过6000字符会明确提示查看全文，列表不会加载整页归档正文。

预算、最高限价和成交金额分开展示，不相加为订单规模。截止时间按当前时间重新评估；争议、失效、暂停、过期或未核验公告不计为开放采购。历史公告仍保留，其意义是研究方向和历史采购记录。

产品对话是分析范围的一部分。同一客户出现在多个产品对话时，从哪个对话进入，就展示和分析该对话产品；API验证实际关联，不能默默切到另一轮画像。旧分析也按对话隔离。

匹配表按“用户产品 → 原文依据 → 条件判断 → 下一步”展示。`方向相关` 表示业务方向有依据，`能力缺口` 表示已披露能力与要求存在明确差异，`待核验` 表示资料不足；三者都不是购买概率。程序检查产品索引、同客户引用编号、连续原文和证据状态，但不能证明自由文本推理的全部语义，界面始终标明AI条件分析。

未知技术规格、资质、联系人职权、剩余预算、订单和公司能力不补造。源网页、附件与用户备注均作为资料，不能执行其中的指令。来源清单按真正纳入的项目/事实引用构建，避免正文有引用而输入缺失原链接。

## Agent 与提示词

- [acquisition.py](../../../backend/app/acquisition.py)：只读采购机会投影；批量读取公告，保守定位买方范围，保留多行技术要求及金额原单位。
- [lead_analysis.py](../../../backend/app/lead_analysis.py)：结构化契约、完整记录裁剪、引用核验、结果账本、输入指纹与失效判断。
- [prompts/acquisition.py](../../../backend/app/prompts/acquisition.py)：采购获客与企业产品匹配模板，明确产品资料、需求证据、事实口径、能力缺口、待核问题和可执行动作。
- 原 `agent.py` / LangGraph / `cached_model` / ToolBroker：标准采购交付最多3客户一批结构化分析，确定性生成回答；手动分析固定目标，只读资料，不启动公网搜索或保存企业事实。

没有新增Agent或数据库迁移。结果存入现有 `ToolCall`，按产品、证据、公告状态、反馈和请求指纹复用；负责人、跟进日期和沟通记录不会单独让产品分析失效。成功分析可跨Job复用，资料改变标记待更新。SDK分析失败显示未完成/部分完成；预算异常和暂停向原控制流传播，原Job可恢复，不重置累计额度。

输入超限按完整记录裁剪，显示纳入/遗漏数量，不截断JSON；超过产品基础资料上限明确失败，不能假装分析全部。匹配原文与AI结论不回写为已核验企业事实。

新增接口：

```text
GET  /api/leads?conversation_id=...
GET  /api/leads/{id}?conversation_id=...
POST /api/leads/{id}/analysis
     {conversation_id, client_token, content?: 分析重点}
```

提示词源码快照由 `scripts/snapshot-agent-prompts.py` 生成并通过 `--check` 核验，不读取密钥、数据库或实际产品文件。
