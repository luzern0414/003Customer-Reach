# 开源采集工具清单

完整机器可读清单位于 `opensource-crawlers/catalog.json`。

2026-09-30 已通过 `git ls-remote --symref ... HEAD` 核验 10 个候选仓库均可访问，并通过 GitHub 仓库目录确认根目录许可证文件存在；这只证明仓库可达和存在许可证文件，不替代正式采用前的许可证条款审查。

## 第一阶段推荐组合

- `Scrapy`：静态页面、分页、限速、重试和数据管道。
- `Playwright`：只处理确实依赖 JavaScript、登录态或交互的授权页面。
- `Trafilatura`：从企业官网提取正文、标题和元数据。
- `RapidFuzz`：企业名称、地址和联系人模糊匹配前的候选计算。
- `python-phonenumbers`：号码格式和号段校验；不能验证号码是否真实有效或同意营销。

## 第二阶段按规模引入

- `Crawlab`：需要多节点、可视化任务管理和运行审计时引入。
- `Airflow` 或 `DolphinScheduler`：定时采集、依赖编排和失败重试变复杂后引入。
- `Splink` 或 `dedupe`：企业主数据规模上升、需要概率实体解析时引入。
- `PaddleNLP`/`HanLP`、`PaddleOCR`：中文字段、证书、营业执照和 PDF 抽取时引入。

## 目标来源策略

### 企查查、1688

只支持有明确授权的 API、合同数据服务或用户提供的人工导出文件。未完成条款和数据许可审查前，不实现登录态批量抓取、验证码处理、接口逆向、绕过频率限制或个人手机号反查。

### 企业官网和门店目录

优先采集公开业务字段，并遵守 robots、服务条款、限速和删除请求。采集结果必须保存 URL、时间和原文摘要，企业公开电话不得扩展推断成个人手机。

### 招投标/采购公告

只接入允许使用的公开数据或授权 API；采购价格和数量按公告证据保存，并标注发布日期和有效期。
