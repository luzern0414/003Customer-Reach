# docs 模块约定

- 项目接续入口是`项目完整提示词与Agent接续执行.md`，运行提示词附录为`Agent运行提示词源码快照.md`；前者写需求、执行边界、架构、真实任务、剩余项和命令，后者保存白名单源码/Skill静态快照及SHA-256。二者不是运行时System Prompt，不注入客户种子或密钥。
- 更新接续文档时核查当前目标/健康/只读数据库，历史测试和旧PID必须标日期；源码快照不导入业务app、不读凭据或客户正文，源提示词/schema/Skill变化后同步校验清单。文档任务不自动恢复paused目标、重启服务、启动真实采集或实现待确认业务模型。

- 保存产品方案、数据来源、采集工具和销售获客设计文档。
- 外部资料必须记录来源 URL、访问/核验日期和用途边界。
- 不把搜索摘要、演示数据或 AI 推断写成已验证事实。
- PPT 原文件保留在本目录；抽取文本和截图只放 `.codex-tmp/`。
- 酒店样本研究见 `酒店智能客服助手_B端客户研究_20260930.md`；联系方式按采购、总机、加盟、预订及 IR 分类，推荐不等于采购意向。
- 集团/品牌与网站运营法律主体、在营门店与开发/签约项目、规模统计日期与采集日期必须分开标注。
- 深圳灯具研究的主文档位于 `.codex-log/20260930164904_深圳灯具客户采集与Excel验证.md`；公开零售价、工程预算上限与零售商实际进货价分开，目录品牌不是供货关系。

- 2026-10-19文档结构：根保留导航与项目进展；`01-商务与需求` 下按需设 `客户资料`、`方案文件`，`02-产品与开发` 下按需设 `设计文档`、`开发记录`，`03-测试与交付` 下按需设 `测试验收`、`交付资料`；图片集中放 `docs/素材/`。每个主目录最多两个分组，分组内直接存文件；不属于分组的文件留在对应主目录，不新增杂项或历史版本目录。不预建空模板，原目录说明仅为历史，当前路径以 `docs/README.md` 为准。
