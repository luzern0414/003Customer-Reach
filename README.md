# DealRadar · AI 智能获客系统

销售用一句话描述产品或输入企业名，系统在招投标与企业信息网站上检索、阅读公告原文，抽取采购方、中标方、金额、联系人等信息并逐字核验原文，输出买家线索与企业档案。

## 能做什么

| 功能 | 说明 |
|---|---|
| 找买家 | “我们做下一代防火墙，找最近两个月采购防火墙的单位” → 检索政府采购网与公共资源交易平台，筛选相关公告，阅读原文，采购方进入线索库并按采购阶段与时间评分 |
| 查企业 | “研究北京航天广通科技有限公司” → 确认企业全称，读取工商信息卡，检索其采购与中标公告，推导客户、供应商、竞争对手 |
| 原文可追溯 | 每个字段都对应来源页面中的原文片段；核验不通过的字段不保存，未披露的信息保持为空 |
| 线索管理 | 状态、负责人、下次跟进、跟进记录、纠错反馈（会写入排除知识）、产品匹配分析、Excel 导出 |
| 人工交接 | 网站需要登录或验证码时任务暂停，在 Edge 中处理后点“继续”；多家同名企业时由用户选择 |

## 数据源（2026-10-28 实测）

| 来源 | 用途 | 状态 |
|---|---|---|
| 中国政府采购网 | 全国政府采购公告；按企业名分年全文检索 | 默认启用，免登录 |
| 全国公共资源交易平台 | 各省公共资源交易公告 | 默认启用，免登录 |
| 全网招标检索（必应） | 各地政府采购网、公共资源交易平台、央企采购平台（如南方电网、中国邮政）的公告直链 | 默认启用，免登录 |
| 百度企业信息 | 企业信息卡（爱企查数据）与百科摘要，确认企业并补充采购方工商信息 | 默认启用，免登录 |
| 采招网 | 国企与企业采购 | 默认关闭，详情需会员登录 |
| 爱企查 | 完整工商信息 | 默认关闭，需登录百度账号 |

数据源在“数据源”页面配置：内置站点可启用或停用；可新增站点（检索地址模板，或填写域名由 LuzCrawl 自动定位站内搜索框），保存前用“测试检索”实际检索一次，确认能取到公告链接并读出正文。千里马、剑鱼、必联网、中国采购与招标网、中国招标网、南方电网、中国移动、云筑网实测无法直接检索，其公告可经全网招标检索取得。

所有采集通过 [LuzCrawl](D:/Codes/Luz-Crawl) 在真实 Edge 中完成，系统不绕过登录、验证码与限流。

## 安装与运行

需要：Windows、Python 3.12+、Node 24+、Microsoft Edge（已加载 LuzCrawl 扩展，`node D:\Codes\Luz-Crawl\scripts\luz-crawl.mjs doctor` 显示 ready）。

```powershell
# 模型配置：复制 config/apikey.example.txt 为 config/apikey.txt 并填写
cd backend
uv venv .venv --python 3.12; uv pip install -p .venv -r requirements.txt
cd ..\web
npm ci; npm run build
cd ..
powershell -File start.ps1     # http://127.0.0.1:8000
powershell -File stop.ps1
```

### 账号与使用次数

- 打开后先登录；没有账号可自行注册。注册用户可发起 **5 次**研究（工作台发送一次或企业主页“继续研究”一次各算 1 次），用完后不能再发起。
- 首次启动自动创建管理员 `admin`，初始密码 `admin`，不限次数，可使用“数据源”“系统设置”。**对外部署前务必改密码**：首次启动前设置环境变量 `DEALRADAR_ADMIN_PASSWORD`。
- 其他环境变量：`DEALRADAR_ADMIN_USERNAME`（管理员用户名）、`DEALRADAR_DEFAULT_QUOTA`（注册用户次数，默认 5）。
- 对话、研究任务、上传资料按账号隔离；企业档案与线索为团队共享。

开发：`backend` 下 `.venv\Scripts\python.exe -m uvicorn app.main:app --port 8000 --reload`；`web` 下 `npm run dev`（/api 代理到 8000）。

测试：`backend` 下 `.venv\Scripts\python.exe -m pytest tests -q`。
